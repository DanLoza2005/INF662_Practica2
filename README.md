# App 3 - QuizRelámpago

Cuestionario con temporizador y resultados finales.

## Funcionalidad
- Banco de al menos 6 preguntas con opciones y respuesta correcta.
- Pantalla de inicio con botón "Comenzar".
- Cada pregunta tiene un temporizador de 10 segundos.
- Al terminar el tiempo o avanzar, se registra el puntaje.
- Pantalla final muestra el resultado y opción de volver a jugar.
- Reto opcional: resalta respuestas correctas/incorrectas y barra de progreso.

# App 2 - GastoDía

Registro de gastos con formulario validado y lista dinámica.

## Funcionalidad
- Formulario con monto, descripción y categoría.
- Validaciones: monto > 0, descripción no vacía, categoría obligatoria.
- Al agregar, se muestra la lista de gastos y el total acumulado.
- Se puede eliminar un gasto y navegar al detalle.
- Maneja correctamente entradas inválidas.
- Reto opcional: resumen/filtro por categoría.

- Incluye buscador para filtrar especies en tiempo real.
